# ⚓ Packaging "Seafarer Calc" as an Android App with Bubblewrap

This application has been rebuilt as a fully compliant **Progressive Web App (PWA)** using React, Vite, and Tailwind CSS. It contains a standard Web App Manifest (`manifest.json`), a vector launcher icon (`icon.svg`), and an offline Service Worker (`sw.js`) that caches assets for mid-voyage high-seas offline use.

To convert this PWA into a native-feeling Android app (`.apk` or `.aab`) for installation on devices or distribution on the Google Play Store, we use Google's **Bubblewrap CLI** (which leverages Trusted Web Activity/TWA technology).

---

## 🛠️ Prerequisites

Before you start, make sure you have:
1. **Node.js** installed on your computer.
2. The app **deployed to a secure HTTPS host** (Vercel, Netlify, Cloud Run, Firebase, etc.). For Bubblewrap, the PWA must be accessible via a public HTTPS URL (e.g., `https://seafarercalc.web.app`).

---

## 🚀 Step-by-Step Packaging Guide

### Step 1: Install the Bubblewrap CLI
Open your computer's terminal (or command prompt) and install the official Bubblewrap CLI globally:
```bash
npm install -g @bubblewrap/cli
```

### Step 2: Initialize Your Android Project
Create a new, empty directory on your computer for the Android project, navigate into it, and initialize Bubblewrap by pointing it to your deployed app's manifest:
```bash
mkdir seafarer-android
cd seafarer-android
bubblewrap init --manifest https://your-deployed-url.com/manifest.json
```
*(Replace `https://your-deployed-url.com` with your actual deployed HTTPS domain).*

### Step 3: Configure Project Parameters
During initialization, Bubblewrap will automatically pull configurations from your manifest and prompt you with questions:
1. **Java & Android SDK:** If you don't have the JDK or Android SDK command-line tools installed, Bubblewrap will ask for permission to **automatically download** and configure them for you. Choose **Yes**.
2. **Package ID:** Enter a unique Android package identifier (e.g., `com.seafarer.calc` or `com.yoursalfred.seafarercalc`).
3. **KeyStore:** Bubblewrap will ask if you have an existing signing key. If not, choose to **generate a new KeyStore**. Enter your password and alias details. *Keep this key and password safe, as you will need it for future updates!*

### Step 4: Build the Signed Android App
Once initialization completes, compile and sign your native Android packages by running:
```bash
bubblewrap build
```
Bubblewrap will ask for your KeyStore password, compile your Trusted Web Activity shell, and produce two main files in your folder:
- 📱 `app-release-signed.apk`: The standard installer file. You can copy this directly to any Android phone to install and test the app.
- 📦 `app-release-bundle.aab`: The Android App Bundle. This is the file you upload to the **Google Play Console** to publish on the Play Store.

---

## 🔒 Step 5: Remove the Browser URL Bar (Digital Asset Links)

To make your Android app look 100% native (by removing the Chrome browser bar at the top of the app), you must establish a secure link of trust between your website and your Android app.

1. Locate the `assetlinks.json` file generated by Bubblewrap in your folder.
2. Upload this file to your web server so it is publicly accessible at:
   ```
   https://your-deployed-url.com/.well-known/assetlinks.json
   ```
3. Once Chrome verifies that the certificate signatures in `assetlinks.json` match your installed APK's signing key, the browser address bar will **automatically disappear**, providing a immersive full-screen native Android experience!

---

## 🧭 Testing Offline Capacity

1. Install the generated `.apk` on an Android device.
2. Open the app while connected to the internet once (this allows the Service Worker at `/sw.js` to pre-cache the layout shells and code assets).
3. Turn on **Airplane Mode** (completely offline).
4. Close and re-open the app. The "Seafarer Calc" app will load instantly and be 100% functional, allowing you to log voyages, calculate NRI progress, and calculate taxes on the high seas with no internet connection!
